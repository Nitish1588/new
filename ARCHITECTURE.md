## Module Dependencies

```mermaid
flowchart TD
    AdminUI[Admin Next.js] --> AdminClient[Admin Axios API wrappers]
    WebUI[Public Next.js] --> WebClient[Public Axios API wrappers]
    AdminClient --> AdminRoutes[/admin route tree/]
    WebClient --> UserRoutes[/user route tree/]
    AdminRoutes --> AdminControllers[Admin controllers]
    UserRoutes --> UserControllers[User controllers]
    AdminControllers --> SharedServices[Application services]
    UserControllers --> SharedServices
    SharedServices --> Tables[TableGateway classes]
    Tables --> DB[(Configured SQL database)]
    Legacy[CodeIgniter app] --> LegacyModels[Legacy models + direct SQL]
    LegacyModels --> LegacyDB[(Configured legacy SQL database)]
```

No source evidence establishes a direct import/runtime dependency between the legacy app and Laminas API.

## API Startup and Request Lifecycle

```mermaid
sequenceDiagram
    participant Client
    participant Front as public/index.php
    participant MVC as Laminas MVC router/bootstrap
    participant Guard as User/Admin controller base
    participant Controller
    participant Service
    participant Table as TableGateway
    participant DB as SQL database
    Client->>Front: HTTP request
    Front->>MVC: Composer autoload + application config
    MVC->>MVC: module route match and controller factory
    MVC->>Guard: dispatch / session gate
    Guard->>Controller: onDispatch
    Controller->>Service: request params / current identity
    Service->>Table: query or mutate
    Table->>DB: SQL
    DB-->>Table: rows / result
    Table-->>Service: models / result
    Service-->>Controller: ResponseModel
    Controller-->>Client: JSON success/data or error envelope
```

The API's common envelope is generated by `AbstractApplicationController`: `{success,data,success_msg,success_code}` or `{success,error_msg,error_code}`. Codes appear in the JSON body; HTTP status mapping requires runtime confirmation. POST parsing is JSON in `AbstractService`; PUT parsing uses `parse_str` on the request body.

## Deployment Evidence

- **CONFIRMED:** both Next apps have `amplify.yml`; admin/public API URLs default to a test API host. The admin app has a local override file template.
- **CONFIRMED:** API contains `Dockerfile`, `docker-compose.yml`, Vagrantfile, and a Composer built-in-server script. These are available deployment/dev options, not proof of production usage.
- **CONFIRMED:** `api/public/.htaccess` rewrites non-file requests to `index.php`; legacy CodeIgniter also uses Apache rewrite config.
- **UNVERIFIED:** actual hostnames, reverse-proxy `/api/public` mount, production database, cloud roles/buckets, TLS termination, CI/CD branch rules, worker fleet, cron, and deployment topology.
- No queue worker or scheduled-job implementation was established in this pass.
